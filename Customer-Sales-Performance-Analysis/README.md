# Customer Sales & Performance Analysis

## Objective
Analyze customer and product sales data to identify revenue trends, customer segments, top products, and business KPIs.

## Business Questions
- Which customer segment generates the most revenue?
- Which products contribute the most revenue?
- How does revenue change month over month?
- Which customers are the highest-value customers?
- What actions could improve sales performance?

## Tech Stack
SQL | Python | Pandas | NumPy | Matplotlib

## Methodology
1. Joined customer, product, and sales datasets.
2. Checked missing values and duplicates.
3. Calculated gross and discount-adjusted revenue.
4. Performed EDA by segment, product, customer, and month.
5. Created SQL queries for business analysis.
6. Visualized the monthly revenue trend.

## How to Run
```bash
pip install pandas matplotlib
cd notebooks
python analysis.py
```
